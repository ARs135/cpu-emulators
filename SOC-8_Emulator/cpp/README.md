## How to run
How to run the scripts? \
Follow these steps (if you don't then uh, the scripts might not work)

1. Compile the script(s) (do `g++ [script.cpp] -o [script.exe]` where `[script]` is the script within the cpp folder you want to run, you might need to have a file path if your CWD not in cpp/. You can do compile flags if you know some :D)
2. Run the script(s) (btw make sure your CWD is the [main folder](../) cuz the main emulator assumes that you are in the main folder. Do `./script` to run it, obviously `script` is the path to the script you compiled, for example, `./cpp/SOC8Emulator.exe`, I haven't compiled the main emulator script cuz I don't want to commit a .exe file to the repo)
